# Аппаратная сертификация

Отчёты повторной сертификации `v0.35.15`:

| Стенд | OpenWrt | PASS | Не применимо | Ошибки |
|---|---|---:|---:|---:|
| Netis NX31 | 25.12.4 | 89 | 4 | 0 |
| OpenWrt x86, VirtualBox | 22.03.5 | 88 | 5 | 0 |

Проверены все 93 команды контракта. `not_applicable` используется только при
отсутствующей capability. На x86 команды конфигурации Wi-Fi проверены по UCI, но
наблюдаемое состояние радио не сертифицировалось: у стенда нет физического
радиомодуля.

Для каждой поддержанной команды проверены доставка, повторная доставка с тем же
ID, deadline, post-condition и предусмотренный контрактом rollback. Полные
машиночитаемые отчёты находятся в `netis-nx31.json` и `openwrt-x86.json`, а
обезличенные результаты и снимки конфигурации находятся в `evidence/`. В отчётах
нет паролей администратора, SSH-паролей и device token.

Повторный запуск описан в [инструкции](../docs/real-router-testing.md).

Дополнительная проверка готовых клиентских режимов `v0.44.0` описана в
[`v0.44.0-client-experience.md`](v0.44.0-client-experience.md).
