# Аппаратная сертификация

Отчёты runtime-сертификации `v0.49.0`:

| Стенд | OpenWrt | PASS | Не применимо | Ошибки |
|---|---|---:|---:|---:|
| Netis NX31 | 25.12.4 | 90 | 4 | 0 |
| OpenWrt x86, VirtualBox | 22.03.5 | 76 | 18 | 0 |

Проверены все 94 команды контракта. `not_applicable` используется только при
отсутствующей capability. На x86 нет физического Wi-Fi-модуля и ряда пакетов,
которые доступны на Netis NX31, поэтому соответствующие операции отмечены как
неприменимые, а не как успешно выполненные.

Для каждой поддержанной команды проверены доставка, повторная доставка с тем же
ID, deadline, post-condition и предусмотренный контрактом rollback. Для
перезагрузки проверяется новый kernel `boot_id`, для отключения агента -
фактическая остановка daemon и возврат связи, для Web SSH - полный цикл PTY с
resize и повторным подключением. Полные
машиночитаемые отчёты находятся в `netis-nx31.json` и `openwrt-x86.json`, а
обезличенные результаты и снимки конфигурации находятся в `evidence/`. В отчётах
нет паролей администратора, SSH-паролей и device token.

После публикации отдельно проверено обновление OpenWrt x86 с агента `0.48.0` на
`0.49.0` файлами GitHub Release. Агент принял подпись, применил bundle, запустил
службу, отправил telemetry и сохранил штатный источник обновлений. Обезличенный
результат находится в
[`signed-release-update.json`](evidence/openwrt-x86/agent.update/signed-release-update.json).

Повторный запуск описан в [инструкции](../docs/real-router-testing.md).

Дополнительная проверка готовых клиентских режимов `v0.44.0` описана в
