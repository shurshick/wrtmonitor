# Надёжность команд

Контракт каждой команды содержит обязательные поля `idempotency`, `delivery`,
`post_condition` и `rollback`. CI отклоняет команду без этой политики.

## Что проверяет CI

- соответствие всех 80 команд серверному registry и dispatcher агента;
- повторную доставку одного UUID без повторного выполнения;
- возврат потерянной команды из `sent` в очередь после lease;
- индивидуальный timeout для чтения, записи и разрывающих связь операций;
- read-after-write telemetry и прямые UCI post-condition для критичных настроек;
- наличие стратегии rollback для каждой изменяющей команды;
- OpenWrt harness с подменами UCI, ubus, firewall и init-сервисов;
- структурированную ошибку с кодом, причиной и признаком допустимости повтора.

## Физический роутер

Аппаратный отчёт создаётся командой:

```sh
python scripts/command_validation_report.py artifacts/physical-router.json --init \
  --router "model / OpenWrt version"
```

Статус `pass` без ссылки на лог, снимок конфигурации или иной артефакт запрещён
валидатором. Разрушающие команды (`sysupgrade`, смена LAN/WAN, reboot, restore)
проверяются только на выделенном тестовом роутере. CI и VirtualBox не выдаются за
физическую проверку.
