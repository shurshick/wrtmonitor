# Release Cleanup 0.55.5

## Область изменений

Один обработчик обновляет журнал команд, отменяет предыдущий запрос и принимает ответ только для текущей страницы. SSE обновления откладываются во время переключения страницы; ссылки сохраняются, пока пользователь нажимает на них. Формы не заменяются.

Проверка WireGuard endpoint не использует regex с неоднозначным повторением. Контракты команд, telemetry и исходная схема базы сохранены.

## Проверки

Результаты CI и Security публикуются для точного коммита выпуска. Браузерный smoke проверяет задержанное обновление журнала, несохранённую форму и PTY roundtrip с тестовым агентом. Deployment acceptance проверяет чистую установку, обновление с 0.55.4, сохранение данных и backup/restore в изолированном PostgreSQL.

Локально пройдены 417 backend/agent-тестов в PostgreSQL, shell harness, Android build/unit/lint. Фактический короткий smoke выполнен 2026-10-04: сервер здоров, Netis передаёт свежую telemetry, Web SSH подтвердил ввод, вывод, resize, reconnect и close. Это установленный агент 0.55.4, кандидат на рабочий стенд не разворачивался. x86 не отвечает на SSH; последняя telemetry 2026-09-02, последняя наблюдавшаяся версия 0.53.1. Новая аппаратная установка/обновление на этих стендах не проверены. [Обезличенный baseline-отчёт](../certification/smoke-v0.55.5.json) не является сертификатом кандидата.

Локальные XML-логи игнорируются; непроверенные исходные аппаратные evidence не удаляются и не попадают в релиз автоматически.

Сохраняются предупреждения deprecated API: Starlette TestClient/httpx и Android EncryptedSharedPreferences. Они не являются найденными уязвимостями; замену транспорта тестов и хранения сессии нужно проверять отдельным изменением после 1.0.
