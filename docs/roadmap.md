# Roadmap WrtMonitor

Цель проекта - максимально полное удалённое управление OpenWrt через Android и Web UI. Ориентир по удобству - мобильное приложение Keenetic, а фактический набор возможностей определяется UCI, ubus и capability report конкретного роутера.

> Все версии до `1.0.0` являются тестовыми. Пометка «реализовано» означает прохождение автоматических контрактных тестов, но не заменяет отдельный протокол проверки на физическом OpenWrt.

## v0.20.0 - интернет и сеть

Статус: реализовано в тестовом релизе.

- WAN DHCP/static/PPPoE и раздельные формы параметров;
- IPv4, IPv6, RA, DHCPv6, DNS, DoT и DoH;
- реальные параметры физических портов;
- bridge, VLAN и пользовательские сегменты;
- Multi-WAN с health-check, failover и возвратом на основной канал.

## v0.3.0 - тестовая основа

- telemetry schema v2: система, hardware, WAN/LAN, Wi-Fi, клиенты и сервисы;
- capability report v5 с динамическим определением функций и причинами недоступности;
- управление WAN, LAN, DHCP, DNS, Wi-Fi, клиентами, firewall и системными сервисами;
- одинаковые capability-aware действия в Android и Web UI;

- PostgreSQL E2E, Chromium desktop/mobile smoke-test и Android build в CI;
- refresh token и автоматическое восстановление Android-сессии;
- Docker/TrueNAS deployment, GitHub Release и GHCR `latest`.

## v0.21.0 - Wi-Fi и клиенты

Статус: запланировано.

- отдельный LuCI-компонент со ссылкой на серверную страницу подключения;
- LuCI не получает права создавать административные mobile pairing tokens;

Прямой поиск роутеров из Android и подключение к OpenWrt в обход сервера из roadmap удалены: они противоречат серверной архитектуре WrtMonitor.
