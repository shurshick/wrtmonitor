# Roadmap WrtMonitor

Все версии до `1.0.0` тестовые. История выпущенных версий находится в [CHANGELOG.md](../CHANGELOG.md), результаты проверок в [docs/testing.md](testing.md), возможности в [матрице поддержки](supported-features.md).

## v0.55.5 - Release Cleanup

- согласованное обновление журнала через SSE и пагинацию;
- проверка задержанных ответов и сохранения введённых настроек;
- обновление поддерживаемых GitHub Actions и совместимых зависимостей;
- закрытие разобранных предупреждений CodeQL с объяснением;
- актуальные инструкции, release notes и порядок обновления.

Статус: выпущен; результаты CI и ограничения smoke описаны в [отчёте](release-cleanup-0.55.5.md).

## v1.0.0 - Public Release

- опубликованные сервер, подписанный агент и Android APK;
- единый проверенный комплект обновлений и контейнерный latest;
- понятные границы поддержки оборудования и операций;
- исправление подтверждённых ошибок ежедневного использования.

Выпуск одобрен владельцем с аппаратным прогоном точного кандидата. Результаты и ограничения: [отчёт 1.0](public-release-readiness.md). Новые функции в этот этап не включены.

## После 1.0.0

- плановое обновление Python, Android Gradle Plugin, Kotlin, Compose и OkHttp как одного совместимого набора;
- доработка ежедневных сценариев по обратной связи;
- расширение аппаратного каталога по обезличенным отчётам реальных устройств.

Отложенные версии зависимостей и причины перечислены в [отчёте cleanup](release-cleanup-0.55.5.md). Многопользовательский режим не планируется.
