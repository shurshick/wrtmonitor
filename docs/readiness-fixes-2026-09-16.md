# Исправления по аудиту готовности

Целевой выпуск: 0.55.3 Release Reliability.

## Изменения

- Общий обработчик обновления и удаления профиля для API и Web отправляет команды также отдельным клиентам. Персональные переопределения сохраняются, при удалении очищается связь с профилем. Проверка всех целей предшествует постановке команд в очередь; сохранение выполняется одной серверной транзакцией. Это не обещает одновременного выполнения всех команд на роутере: результат каждой команды по-прежнему подтверждает агент.
- CSP допускает динамические элементы CSS только на странице терминала. ANSI-цвета и моноширинный шрифт проверены в реальном Chromium в обеих темах на desktop/mobile.
- WebSocket закрывается с кодом 1000 при завершении агентом сессии. Итоговый статус не заменяется ложной ошибкой связи; события прежнего соединения не меняют новое.
- Продвижение в latest проверяет точный коммит тега, успешные CI/Security, обязательные jobs, семь артефактов и OCI-метаданные контейнера. Публикация указателя использует digest; параллельные продвижения сериализованы.
- Начальная схема PostgreSQL заморожена в независимом снимке. Добавлены правила миграций и отката через резервную копию.
- Устранено автоматическое доверие неизвестным SSH-ключам стенда, ограничены входные строки перед regex, исключена выдача текстов внутренних исключений. Отдельно записан разбор 17 предупреждений CodeQL.

## Что не утверждается

На Netis и рабочем OpenWrt x86 новые изменения в этом проходе не разворачивались. PostgreSQL работала в отдельном временном локальном кластере; рабочий сервер не менялся. Браузерный прогон использует тестовый агент, а не физический PTY.

Старые аппаратные результаты не подменялись новыми, fingerprint длительного прогона не переписывался. Владелец явно разрешил полный выпуск 0.55.3 без нового длительного прогона. Исключение хранится отдельно в `certification/release-exception-v0.55.3.json`, привязано к версии и исходному коду и не распространяется на следующие версии. Автоматические CI/Security остаются обязательными; актуальные результаты публикуются в GitHub Actions.
