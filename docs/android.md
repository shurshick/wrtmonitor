# Android-приложение

Android-приложение - основной пользовательский интерфейс `WrtMonitor`.

Текущая версия берётся из файла `VERSION` и отображается на странице последнего GitHub Release.

## Установка

1. Откройте последний тестовый релиз WrtMonitor.
2. Скачайте APK:

   ```text
   wrtmonitor-android-v<версия>.apk
   ```

3. Установите APK на Android-устройство.
4. В Web UI сервера откройте **Аккаунт -> Подключить мобильное приложение** и создайте одноразовый QR.
5. В Android нажмите **Сканировать QR**, проверьте адрес сервера и подтвердите подключение.

Альтернативный способ: вручную укажите адрес сервера и войдите логином и паролем владельца:

   ```text
   https://monitor.example.ru
   ```

Пароль владельца, access token, refresh token и device token агента в QR не включаются. QR действует 10 минут и только один раз.

Сессия хранится в зашифрованном хранилище. После сна телефона, временной потери сети или пересоздания Activity приложение восстанавливает поток событий автоматически. Истёкший access token обновляется через refresh token без повторного ввода пароля; при окончательно отозванной сессии приложение возвращает пользователя на вход.

На экране **О приложении** действия разделены: **Скачать обновление** загружает APK, а **Страница релиза** открывает описание выпуска без загрузки файла.

## Что уже работает

- ввод адреса сервера при первом запуске;
- подключение к серверу одноразовым QR-кодом;
- запрос разрешения камеры только при открытии сканера;
- проверка типа, версии, URL и подтверждение домена/IP перед обменом;
- вход администратора через backend API;
- безопасное хранение access/refresh token через `EncryptedSharedPreferences`;
- автоматическое обновление истёкшей сессии без повторного ввода пароля;
- список роутеров;
- компактные карточки роутеров со статусом и меню действий;
- пять основных вкладок после выбора роутера: обзор, клиенты, Wi-Fi, интернет и «Ещё»;
- отдельный каталог сетевых правил, VPN, системы и настроек приложения;
- иерархическая навигация назад без потери выбранного роутера;
- живой обзор роутера с графиком скорости, ресурсами, интернетом, клиентами и Wi-Fi;
- диапазоны графика 2 часа, 24 часа, 7 и 30 дней;
- выбор конкретного Wi-Fi radio с фактическими каналом, режимом, регионом и мощностью;
- рабочие разделы со сводкой, основными действиями и раскрываемыми расширенными настройками;
- telemetry, клиенты, Wi-Fi, интернет, сетевые правила, VPN, система и agent status;
- статические DHCP-выдачи;
- несколько SSID, radio, канал, ширина, мощность, расписание, roaming и Mesh;
- переподключение интерфейсов и перезапуск сети;
- hostname и перезапуск ключевых OpenWrt-сервисов;
- WAN DHCP/static/PPPoE, LAN, DNS и проброс портов;
- DHCP pool, блокировка клиентов и гостевой Wi-Fi;
- постоянный реестр клиентов, общие профили клиентов и Wi-Fi-сетей, расписания и ограничения скорости;
- история RX/TX по клиентам и общая настройка SQM;
- timezone и NTP;
- обслуживание агента и compact capabilities summary в разделе системы;
- capability-aware управляющие действия;
- diagnostics;
- экран "О приложении";
- единая WrtMonitor Material 3 дизайн-система со светлой и тёмной темой;
- edge-to-edge с корректными системными отступами и экранной клавиатурой;
- нижняя навигация на телефоне и Navigation Rail на экранах от 720 dp;
- унифицированные статусы с цветом, иконкой и текстом;
- единые состояния загрузки, пустых данных, ошибок и недоступного роутера.
- IPv6, Multi-WAN, маршруты, DDNS, UPnP и расширенные правила firewall.
- WireGuard, OpenVPN client, policy routing и VPN telemetry.

## Обновление APK

APK подписывается отдельным production-ключом WrtMonitor. При переходе с `v0.9.0` и более раннего debug APK нужна одна чистая установка: Android не разрешает обновление приложения с другим ключом подписи. Начиная с `v0.10.0` последующие версии устанавливаются поверх без удаления, а GitHub Release больше не публикует debug APK.

Источник версии для Android-сборки теперь один: `VERSION` и `VERSION_CODE` в корне репозитория. Это убирает старую проблему, когда имя релизного APK и фактическая версия приложения расходились.

## Ограничения текущей версии

- команды выполняются через очередь и приходят при следующем polling agent;
- Android всегда работает через WrtMonitor Server; агент устанавливается на OpenWrt отдельно;
- отдельные команды доступны только при наличии соответствующей capability на конкретном OpenWrt-роутере.

## Интерфейс 0.54.0

Редизайн не меняет API и не создаёт показатели, отсутствующие в telemetry. Исторический график показывает только периоды, которые предоставляет сервер. Неподдерживаемые Wi-Fi, VPN или аппаратные функции получают явное состояние вместо пустой формы.

Основные экраны проверены на Android 15 в RU/EN, светлой и тёмной теме, портретной и широкой конфигурации. Подробный аудит и ограничения: [android-redesign-0.54.0.md](android-redesign-0.54.0.md).
