# Лицензия: решение владельца

Проверка 2026-10-05: корневого LICENSE и лицензии проекта в README, Android metadata, backend и документации нет. Android содержит copyright © 2026 Alexandr Kovalenko. MIT-файлы в `backend/app/static/vendor/xterm*` относятся только к сторонним компонентам, не ко всему WrtMonitor.

До решения владельца репозиторий нельзя представлять как проект с установленной open-source лицензией. Публичность GitHub сама по себе не заменяет лицензию. Новая лицензия не назначена автоматически.

После подтверждения: добавить корневой LICENSE, согласовать copyright, ссылки README и документации, проверить совместимость условий распространяемых зависимостей. Сторонние лицензии сохраняются отдельно.
