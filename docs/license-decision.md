# Лицензия: решение владельца

**Решение владельца от 05.10.2026: Apache License 2.0 (SPDX: Apache-2.0).**

При первоначальном аудите лицензия проекта не была определена. После явного выбора владельца добавлен [LICENSE](../LICENSE) с неизменённым стандартным текстом [Apache](https://www.apache.org/licenses/LICENSE-2.0.txt), ссылка README и copyright Alexandr Kovalenko, уже указанный в Android.

Копия лицензии включена в Android assets, подписанный набор файлов агента и будущие release assets/checksum inventory. Образ сервера содержит корневой LICENSE. Лицензии vendored xterm/xterm-addon-fit (MIT) сохранены отдельно. Условия внешних зависимостей не переопределяются лицензией проекта.

Выбор лицензии закрывает юридический блокер подготовки; это не одобрение stable и не разрешение автоматически выпускать v1.0.0. Аппаратный прогон и release decision остаются обязательными.
