# v0.18.0-truth-layer — достоверные данные

Тестовый релиз меняет базовый контракт telemetry и намеренно требует чистую PostgreSQL БД.

## Изменения

- состояния данных: `configured`, `observed`, `unsupported`, `stale`, `error`;
- отсутствующие значения передаются как `null`, а не как вымышленные нули;
- сервер принимает только telemetry schema v2;
- Android понимает неизвестные точки истории и не соединяет их с графиком;
- после записи конфигурации агент обновляет telemetry до завершения команды;
- схема БД сведена к единственному baseline revision.

## Обновление тестового стенда

Удалите старый PostgreSQL volume и разверните сервер заново. Затем повторно подключите роутер и Android. Сохранение данных между ранними тестовыми версиями пока не гарантируется.
