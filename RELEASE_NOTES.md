# WrtMonitor v0.35.14 — доверие к обновлениям

Тестовый релиз восстанавливает проверяемую цепочку обновления старых OpenWrt-агентов.

## Изменено

- агент и установщик доверяют текущему и предыдущему RSA-ключам;
- неизменный Ed25519 trust anchor обеспечивает переход со старых агентов;
- CI проверяет подпись текущего manifest ключом, встроенным в `v0.32`;
- сборка отклоняется, если Android `VERSION_CODE` не увеличен;
- Android APK получил `versionCode=88`.

## Проверки

- криптографический тест update chain;
- тест обеих доверенных RSA-веток;
- проверка согласованности всех release metadata;
- полный backend, agent и Android test suite.

Релиз остаётся тестовым и сначала публикуется как prerelease.
