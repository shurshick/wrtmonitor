# WrtMonitor v0.45.0 - Wi-Fi Experience

Тестовый релиз убирает ручной ввод пароля при подключении по QR и сводит Wi-Fi в один честный контракт для агента, сервера, Web UI и Android.

## Изменено

- радиомодули показывают отдельно настроенное и фактическое runtime-состояние;
- список каналов берётся у драйвера выбранного radio, а не хранится в интерфейсе;
- состояние, канал, регион, режим и мощность применяются одной операцией;
- действующие Wi-Fi-сети получили кнопку одноразового QR;
- агент читает SSID, защиту и ключ непосредственно из UCI OpenWrt;
- QR не требует ручного ввода пароля и строится локально в Web UI или Android;
- Wi-Fi URI не сохраняется в PostgreSQL, кэше агента и журнале операций;
- устройства без физического radio PHY больше не показывают неработающие Wi-Fi-настройки.

## Проверки

- `224` backend-теста;
- `48` тестов OpenWrt-агента;
- Android compile и unit tests;
- Netis NX31: два физических радиомодуля, наблюдаемая telemetry и одноразовый QR;
- OpenWrt x86 без Wi-Fi: `unsupported / no_wifi_radio`, Wi-Fi и QR capabilities выключены.

Android `versionCode`: `102`.
