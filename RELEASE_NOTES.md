# v0.16.1-agent-recovery — восстановление связи агента

## Что изменилось

- Исправлена повторная установка поверх оставшегося UCI-конфига: новая привязка больше не смешивается со старым token.
- Installer останавливает прежний daemon, отправляет первую telemetry и проверяет запуск службы до сообщения об успехе.
- Сервер автоматически создаёт команду обновления при получении telemetry от устаревшего агента с включённым автообновлением.
- Обновление и rollback по серверной команде сразу перезапускают код агента через безопасный handoff.
- Фоновая самостоятельная проверка обновлений выполняется каждый час вместо шести часов.

## Обновление

1. В TrueNAS откройте Custom App, нажмите **Edit → Save**. Образ `ghcr.io/shurshick/wrtmonitor:latest` скачивается заново благодаря `pull_policy: always`.
2. Дождитесь состояния `/ready` = `200 OK`.
3. Старый агент получит `agent.update` после ближайшей telemetry. Также можно нажать **Проверить и обновить**.
4. Если прежняя привязка уже удалена из БД, повторно запустите installer `0.16.1`: сохранённый конфиг будет исправлен автоматически.
5. Android APK можно установить поверх предыдущей версии. `versionCode` повышен до `61`.

Перед обновлением сервера рекомендуется создать резервную копию PostgreSQL.
