# WrtMonitor v0.35.16 — устойчивый Web-терминал

Тестовый релиз заменяет старый экспериментальный SSH-туннель на полноценную PTY-сессию OpenWrt.

## Исправлено

- `xterm.js` и addon подгонки размера встроены в образ сервера и больше не блокируются CSP или недоступностью CDN;
- каждая вкладка терминала получает отдельный UUID сессии, поэтому параллельные подключения не смешивают ввод и вывод;
- состояние сессий и кадры хранятся в PostgreSQL, а не в памяти одного процесса сервера;
- агент запускает `/bin/ash -i` в настоящем PTY через пакет `script-utils`, передаёт изменение размера и восстанавливает HTTP-потоки после краткого обрыва;
- сессия привязана к конкретному device token, WebSocket требует авторизованную cookie и совпадающий Origin;
- активная сессия истекает через 30 минут бездействия, завершённые данные очищаются через сутки.

## Проверки

- добавлен PostgreSQL E2E `browser WebSocket -> server broker -> agent API -> browser output`;
- Chromium smoke-test печатает маркер в локальный xterm и проверяет возврат вывода;
- добавлен аппаратный runner `scripts/terminal_hardware_e2e.py` для полного пути `Chromium -> WrtMonitor -> OpenWrt PTY`;
- аппаратный путь пройден на OpenWrt x86: браузер получил вывод реального `/bin/ash` из PTY с отдельным UUID сессии;
- проверены чистая миграция и обновление существующей схемы с `0002`.

Android `versionCode`: `90`.
