# v0.22.0-firewall-vpn — Firewall и VPN

Тестовый релиз завершает фактическое управление периметром и VPN без ручных ссылок на синтетические имена.

## Изменения

- полный CRUD правил firewall, зон, транзитов, NAT redirect и статических маршрутов по UCI section;
- наблюдаемое состояние WireGuard, OpenVPN и PBR, включая runtime, handshake и счётчики;
- импорт, экспорт, включение, отключение и удаление VPN-профилей;
- VPN и сетевые команды защищены автоматическим rollback при потере связи;
- Web UI управляет существующими записями прямо из списков.

## Проверка

Backend, Android, shell syntax, OpenWrt harness и контракты команд проверяются автоматически. Разрушающие сценарии потери WAN требуют отдельной проверки на физическом роутере.
