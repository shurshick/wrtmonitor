# WrtMonitor v0.41.0 - Clients And Devices

Тестовый релиз приводит клиентов домашней сети к единой модели в сервере, Web UI и Android.

## Изменено

- клиент сохраняет идентичность по MAC при смене IP-адреса и интерфейса;
- private/randomized MAC не объединяются по совпавшему IP, чтобы разные устройства не склеивались;
- тип устройства определяется автоматически и может быть исправлен пользователем;
- ручной тип имеет приоритет и не перезаписывается следующей telemetry;
- сохраняется ограниченная история переходов `online`, `recent` и `offline`;
- Web UI и Android показывают одинаковые типы, значки и историю присутствия;
- API получил детальную карточку клиента, историю активности и приращения RX/TX между точками трафика;
- миграция PostgreSQL сделана идемпотентной для чистого развёртывания и существующей базы.

## Проверки

- 259 backend и OpenWrt agent тестов, включая PostgreSQL schema E2E;
- проверка 93 контрактов команд и архитектурных границ;
- browser smoke test Web UI;
- Android unit tests, lint, debug/release build и emulator UI tests;
- Docker build и smoke test;
- CodeQL для Python и Java/Kotlin.
