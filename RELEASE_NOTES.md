# WrtMonitor v1.0.0 - кандидат публичного выпуска

Кандидат ещё не опубликован. Выпуск разрешён владельцем после нового аппаратного прогона и проверок GitHub; прежние отчёты не подтверждают этот кандидат.

## Исправлено

- Публичные аппаратные и диагностические отчёты используют разрешённый набор полей, без raw UCI, системных журналов и аргументов процессов.
- JWT требуют обязательные claims; обработка архивов восстановления ограничивает размер, пути и типы файлов.
- Резервные копии сервера создаются в уникальных временных файлах с закрытыми правами доступа.
- Android корректно различает публичные имена серверов и локальные IPv6-адреса.
- Заданы обязательный пароль PostgreSQL и проверки ошибок подключения агента.

## Подготовка публичного выпуска

- Apache License 2.0 включена в сервер, APK, архив агента и файлы выпуска. Лицензии сторонних компонентов сохранены.
- Добавлены Quick Start, границы аппаратной совместимости, сравнение решений и troubleshooting.
- Полный release inventory содержит commit, версии и immutable digest контейнера; контрольные суммы подписываются Ed25519 и RSA.
- Stable gate требует полный физический E2E именно кандидата и отдельное решение владельца.

## Обновление

После публикации: штатное обновление сервера через Docker/TrueNAS, агента через подписанный manifest, Android через подписанный APK. Чистая установка не требуется для версионированной БД 0.55.5; перед обновлением сохраните резервную копию. Android `versionCode`: `126`.

## Проверки и границы

Локально на кандидате: 453 теста, OpenWrt harness и responsive browser smoke прошли. Новый CI и аппаратный прогон пока не завершены; подписанные production assets ещё не созданы. Фактические результаты: [подготовка публичного релиза](docs/public-release-readiness.md).

Ограничения: single-owner, поддержка зависит от capabilities роутера; VM без Wi-Fi не подтверждает Wi-Fi. Эмулятор Android не заменяет ручную проверку на телефоне. Многодневный soak нового кандидата не выполнялся.
