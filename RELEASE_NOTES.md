# WrtMonitor v0.45.1 - Wi-Fi State Consistency

Тестовый исправляющий релиз приводит фактическое состояние Wi-Fi, настройки радиомодуля и расписание к одному контракту в агенте, Web UI и Android.

## Исправлено

- фактическое runtime-состояние радиомодуля больше не подменяется значением `wireless.disabled`;
- настройка владельца отделена от временного отключения Wi-Fi по расписанию;
- Web UI и Android показывают одно расписание для конкретного выбранного радиомодуля;
- выключенное расписание больше не сохраняет на экране старые дни и часы;
- при переключении 2.4/5/6 ГГц формы получают канал, регион, режим, гостевую сеть и Mesh выбранного диапазона;
- пустой пароль существующей гостевой сети или Mesh сохраняет действующий ключ;
- после изменения радио и расписания агент проверяет фактический результат;
- карточки радиомодулей больше не создают горизонтальную прокрутку на телефоне.

## Проверено

- Netis NX31: `radio0` 2.4 ГГц, канал 1, runtime включён; `radio1` 5 ГГц, канал 36, runtime включён;
- на Netis NX31 выключенное расписание корректно передаётся как выключенное для Web UI и Android;
- отсутствие Wi-Fi на OpenWrt x86 покрыто автоматическим сценарием `unsupported / no_wifi_radio`;
- backend, OpenWrt harness, browser smoke на desktop/mobile, Android unit/lint/build и Android emulator UI tests;
- подписанный Android APK имеет `versionCode` 103.
