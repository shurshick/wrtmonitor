# WrtMonitor v0.44.0 - Client Experience

Тестовый релиз делает ежедневное управление клиентами короче и понятнее.

## Изменено

- добавлены режимы «Без ограничений», «Ребёнок», «Гость» и «Умное устройство»;
- Web UI и Android используют общий каталог режимов и вариантов скорости с сервера;
- лимиты выбираются в Мбит/с, ручной ввод Кбит/с больше не нужен;
- рядом с лимитом показана текущая скорость по реальным счётчикам клиента;
- блокировка интернета и закрепление текущего IPv4 вынесены в быстрые действия;
- режим с лимитами скрывается, если роутер не подтвердил поддержку traffic control;
- выбранный режим определяется по фактической политике и не требует изменения схемы БД.
- исправлена старая инверсия расписания: заданные дни и часы теперь означают
  разрешённый доступ, а не период блокировки.

## Проверки

- backend и OpenWrt agent tests;
- Android unit tests и сборка APK;
- Web UI smoke и проверка серверного каталога;
- применение политик и post-condition на Netis NX31 и OpenWrt x86.

Android `versionCode`: `101`.
