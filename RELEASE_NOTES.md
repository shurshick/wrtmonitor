# v0.32.0-push-reliability

Тестовый релиз быстрого получения команд и живого обновления открытых интерфейсов.

## Изменения

- агент держит long-poll до 25 секунд и получает новую команду сразу после её фиксации в PostgreSQL;
- прежний короткий `GET /api/v1/agent/commands` сохранён для старых агентов;
- цикл агента учитывает отдельный deadline telemetry и не меняет заданную периодичность мониторинга;
- ошибки связи используют backoff 5–60 секунд без горячего цикла запросов;
- Web UI и Android используют один SSE endpoint для telemetry и жизненного цикла команд;
- периодический опрос интерфейсов оставлен как резервный механизм с интервалом 30 секунд;
- сервер публикует realtime-метрики и защищает подписчиков от переполнения очереди через принудительную синхронизацию.

## Проверка

- broadcast и пробуждение long-poll проверены для 100 одновременных агентов;
- проверена совместимость короткого polling и повторная выборка команды после пробуждения;
- Android SSE-клиент проверен через MockWebServer;
- полный Python, agent harness, Android unit/build и browser smoke входят в release CI.

Обновление базы не требуется. Realtime рассчитан на foreground Web UI и Android; системные push-уведомления при закрытом приложении в этот релиз не входят.
