# v0.31.2-dns-recovery

Тестовый hotfix потери DNS после установки компонентов зашифрованного DNS.

## Изменения

- установка `https-dns-proxy` и `stubby` сохраняет исходную конфигурацию `dnsmasq` до запуска package post-install;
- отключение DoH/DoT восстанавливает DNS и удаляет оставленные пакетом служебные upstream-порты;
- при ошибке установки агент выполняет аварийное восстановление исходной конфигурации;
- установка и переключение DoH/DoT требуют успешного DNS-запроса, а не только наличия пакета.
- список доступных обновлений пакетов больше не растягивает страницу обслуживания и раскрывается по запросу.

## Проверка

- Netis NX31: `dns.install_doh` и `dns.set_doh` прошли через серверный API;
- OpenWrt x86: тот же сценарий прошёл без потери DNS;
- после команд на обоих стендах проверены DNS, отправка telemetry и работа демона агента.
