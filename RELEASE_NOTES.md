# WrtMonitor v0.55.1 - Web Terminal Layout

Патч исправляет компоновку Web SSH после редизайна `0.55.0`. Backend API, авторизация, telemetry и команды агента не менялись.

## Исправлено

- удалён повторяющийся заголовок «Терминал» над карточкой Web SSH;
- desktop-карточка терминала целиком помещается в видимую область;
- на телефоне сохранена компактная рабочая область с естественной короткой прокруткой;
- добавлены браузерные проверки заголовка и размеров карточки;
- стабилизирована инициализация постраничной навигации журнала команд и поиска установленных пакетов.

Web SSH roundtrip, desktop `1440x900` и mobile `390x844` проверены в CI. Новый снимок терминала получен из того же браузерного прогона.

Фиктивные данные и неподдерживаемые операции не добавлены. Runtime OpenWrt не менялся; аппаратное soak evidence Netis NX31 и OpenWrt x86 наследуется по совпадающему fingerprint. Android `versionCode`: `121`.

Все версии до `1.0.0` остаются тестовыми.
