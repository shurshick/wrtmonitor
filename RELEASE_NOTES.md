# WrtMonitor v0.35.17 — исправление терминального транспорта

Тестовый hotfix устраняет зависание Web-терминала в состоянии «Агент создаёт PTY».

## Исправлено

- `agent.ssh_session` больше не возвращает `SUCCESS` сразу после запуска фонового процесса: агент ждёт готовности PTY и обоих направлений HTTPS;
- бесконечная загрузка FIFO через один `curl` заменена конечными порциями вывода;
- файловый дескриптор FIFO остаётся открытым между HTTP-запросами, поэтому вывод shell больше не теряет символы;
- запуск не использует отсутствующую в старом BusyBox опцию `start-stop-daemon -O`;
- при ошибке запуска журнал команд получает конкретную причину или timeout готовности.

## Проверки

- добавлены регрессии конечной передачи FIFO и readiness handshake;
- исправлен аппаратный runner: Enter отправляется отдельным терминальным событием;
- полный путь `Chromium -> WebSocket -> WrtMonitor -> OpenWrt agent -> PTY -> xterm` пройден на OpenWrt x86 через публичный HTTPS-сервер, подтверждён реальный вывод `uname`;
- терминальный обмен проверяется отдельно от telemetry.

Android `versionCode`: `91`.
