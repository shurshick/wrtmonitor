# WrtMonitor v0.46.0 - Architecture Cleanup

Тестовый технический релиз закрывает архитектурный долг из аудита `0.45.2`. Пользовательские контракты, PostgreSQL и TrueNAS YAML не менялись.

## Изменено

- Android API разделён на компактный фасад, общий HTTP-транспорт, авторизацию, операции и JSON-преобразования;
- VPN-управление вынесено из общего сетевого экрана;
- карточки модели, процессора и температур больше не продублированы в Compose;
- стили Web UI разделены на основу, компоненты и адаптивные правила;
- CI не допускает повторного разрастания ключевых Android и Web-файлов.

## Проверено

- совместимость публичных методов `WrtMonitorApi` и сборка Android;
- архитектурные ограничения и Web UI regression tests;
- backend, OpenWrt harness, Android unit tests, lint и сборка APK;
- согласованность метаданных релиза и контрольных сумм.

Сервер обновляется обычным redeploy образа `latest` после публикации релиза. Агент получит `0.46.0` через штатное автообновление.
