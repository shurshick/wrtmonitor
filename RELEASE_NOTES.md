# v0.24.1-ui-unification — Единый интерфейс

Тестовый патч-релиз приводит обслуживание и общую тему Web UI и Android к единому виду.

## Изменения

- Web UI и Android получили отдельный сохраняемый переключатель светлой и тёмной темы;
- список init-служб теперь прокручивается внутри ограниченного блока;
- карточки обслуживания выровнены и не растягивают страницу в бесконечное полотно;
- на странице со списком роутеров добавлена подтверждаемая команда перезагрузки;
- desktop/mobile browser smoke проверяет обе темы и компоновку обслуживания.

## Проверка

Backend, Android, shell syntax, OpenWrt harness и контракты команд проверяются автоматически. Опасные действия на физическом роутере требуют отдельного подтверждённого прогона.
