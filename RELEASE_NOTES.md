# WrtMonitor v0.51.0 - Public Beta

Первый релиз для публичного бета-тестирования ежедневных сценариев. Это ещё не стабильная версия `1.0`.

## Диагностика и отчёты

- проверка сети запускается одной кнопкой в Web UI и Android;
- Web UI скачивает безопасный JSON-отчёт выбранного роутера;
- Android передаёт тот же отчёт через системное меню;
- серверный ZIP включает очередь команд, свежесть агентов, уведомления и отчёты активных роутеров;
- пароли, токены и сырая конфигурация в отчёты не попадают.

## Обратная связь

- в Web UI добавлена форма отзыва и список последних отправленных сообщений;
- в Android форма находится на экране «О приложении»;
- сообщения сохраняются на собственном сервере WrtMonitor и не отправляются сторонним сервисам.

## Проверки

- backend и OpenWrt: 320 локальных тестов;
- Android: unit tests, компиляция и debug APK;
- PostgreSQL migration/E2E выполняются в обязательном GitHub CI;
- Android `versionCode`: `111`.

Матрица возможностей: `docs/supported-features.md`.
