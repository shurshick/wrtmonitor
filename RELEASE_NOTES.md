# WrtMonitor v0.55.3 - Release Reliability

Исправления по аудиту готовности. Выпуск в основном канале, включая контейнерный `latest`.

## Исправлено

- Изменение и удаление профилей доступа распространяется на отдельных клиентов и Wi-Fi. Персональные настройки клиентов сохраняются.
- Web SSH: восстановлены динамические стили xterm, ANSI-цвета и моноширинный шрифт в обеих темах. Нормальный выход больше не отображается как потеря связи; старое соединение не меняет состояние нового.
- Начальная схема PostgreSQL зафиксирована независимо от текущих моделей. Документированы обновление и восстановление базы.
- Проверяются SSH-ключи стендов, ограничена длина входных идентификаторов, внутренние исключения не раскрываются в ответах API.
- Перед обновлением `latest` проверяются точный коммит, CI/Security, семь артефактов и метаданные образа. Контейнер продвигается по digest.
- Исправлена подготовка Android SDK в CI: удалён запрос устаревшего пакета `tools`.

## Проверки и ограничения

Локально выполнены 310 backend-тестов с PostgreSQL и 93 теста агента, shell harness, полный браузерный прогон, чистые миграции и backup/restore PostgreSQL. Дополнительно добавлены проверки исключения из длительного прогона. Выпуск и продвижение требуют успешного GitHub CI, включая Android и эмулятор, контейнер и проверку развёртывания.

**Новый длительный прогон 7–14 дней на Netis NX31 и OpenWrt x86 не выполнялся. Владелец явно разрешил полный выпуск без него.** Это отдельное исключение для 0.55.3, а не новый сертификат и не повторное использование старого отчёта для изменённого backend. Браузерные тесты используют тестовый агент, не физический роутер. Код runtime агента не менялся, кроме номера версии.

Android `versionCode`: `123`. Перед обновлением сервера сохраните резервную копию БД; порядок описан в `docs/database-upgrades.md`.

Все версии до `1.0.0` остаются тестовыми.
