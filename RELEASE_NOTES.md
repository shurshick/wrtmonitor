# v0.29.0-network-policy

Тестовый релиз сетевых политик. Docker-образ публикуется как versioned и `canary`; `latest` остаётся на выдержанной версии.

## Изменения

- SQM получил профили для обычной сети, игр и потокового видео, а также недельное расписание;
- клиентские политики умеют направлять DNS через Cloudflare Security или Family и блокируют обход через DoT;
- переходы Multi-WAN записываются только при фактическом изменении runtime-состояния;
- Firewall и VPN получили готовые шаблоны без ручного набора типовых параметров;
- сервер загружает официальный каталог OpenWrt по версии, target и board name конкретного роутера;
- Web UI и Android выбирают совместимый sysupgrade-образ из каталога, ручной URL оставлен аварийным вариантом.

## Проверка

- backend/API, OpenWrt agent и contract tests;
- Android unit, lint и debug build;
- тесты нормализации расписания, Multi-WAN и фильтрации официальных sysupgrade-образов.
