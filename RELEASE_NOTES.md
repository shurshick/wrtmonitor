# v0.33.0

Тестовый релиз масштабируемого брокера событий и оффлайн-буфера телеметрии.

## Изменения

- брокер `RealtimeBroker` переведён с In-Memory структуры на PostgreSQL `LISTEN/NOTIFY`, что позволяет горизонтально масштабировать бэкенд и обрабатывать события от агентов на нескольких узлах (multi-instance);
- добавлен эндпоинт `/metrics` в формате Prometheus для мониторинга состояния самого бэкенда (счётчики, очереди, wakeups);
- OpenWrt-агент теперь сохраняет данные телеметрии во временный буфер `/tmp/wrtmonitor_telemetry_buffer.jsonl` в случае потери связи с сервером;
- при восстановлении соединения агент безопасно считывает буфер и досылает накопленные кадры на сервер;
- исправлен баг дублирования телеметрии (data duplication) при частичном сбое сети и устранены предупреждения `shellcheck` `SC2094`;
- обновлены зависимости Python и Android до актуальных версий (безопасность и стабильность).

## Проверка

- PostgreSQL-брокер покрыт юнит-тестами с имитацией вызовов базы (`listen_to_postgres`);
- оффлайн-буфер проверен на реальном аппаратном роутере Netis NX31 с использованием отключения сети (iptables DROP);
- полный Python, agent harness, Android unit/build и browser smoke входят в release CI.

Обновление базы не требуется (PostgreSQL-брокер использует встроенную функцию `pg_notify` и не требует новых таблиц).
