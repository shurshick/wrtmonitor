# WrtMonitor v0.55.5 - Release Cleanup

Исправления надёжности и подготовка к публичному выпуску.

## Исправлено

- SSE и переключение страниц журнала больше не заменяют ссылки во время нажатия.
- Запоздалый фоновый ответ не возвращает журнал на предыдущую страницу.
- Изменённые значения форм сохраняются при обновлении журнала.
- WireGuard endpoint проверяется линейным разбором; malformed адреса и порты отклоняются.
- Обновлены совместимые серверные зависимости, Android Security Crypto и GitHub Actions с поддержкой Node.js 24.
- Roadmap очищен от устаревших статусов уже выпущенных версий.

## Обновление

Штатное обновление сервера через Docker/TrueNAS, агента через подписанный manifest, Android через подписанный APK. Начальная схема PostgreSQL и UCI-конфигурация не изменены. Android `versionCode`: `125`.

## Проверки и границы

Обязательны CI, Security, Android emulator, signed APK, чистая установка и обновление серверного контейнера с сохранением базы. Отчёт с фактическими результатами, доступностью стендов и отложенными зависимостями: [Release Cleanup](docs/release-cleanup-0.55.5.md).

Новый многодневный аппаратный прогон исключён владельцем при поручении этого cleanup; прежние сертификаты не выдаются за результаты новой версии. Все версии до `1.0.0` остаются тестовыми.
