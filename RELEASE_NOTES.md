# WrtMonitor v0.50.1 - Beta Readiness

Исправляющий тестовый релиз закрывает критерии Beta Readiness, которые не были выполнены в преждевременно опубликованном `v0.50.0`.

## Развёртывание и восстановление

- CI обновляет сервер с предыдущего неизменяемого образа на новый образ с той же PostgreSQL-базой и проверяет сохранность администратора и роутера;
- отдельно проверяется установка сервера на пустую базу;
- TrueNAS YAML проходит проверку Docker Compose;
- PostgreSQL backup проходит создание, проверку и восстановление во временную базу;
- тестовый тег больше не получает Docker-тег `latest` автоматически;
- перевод в `latest` разрешён только при наличии принятого отчёта Beta Readiness.

## Android

- поток событий автоматически восстанавливается после пропажи сети с ограниченной экспоненциальной задержкой;
- `401` останавливает переподключение и запускает штатное обновление access token;
- зашифрованная сессия проверяется после пересоздания Activity;
- ошибки HTTP и команд показываются понятным текстом вместо голого `HTTP 401` или `failed`;
- экран «О приложении» имеет компактную структуру;
- «Скачать обновление» действительно загружает APK, а «Страница релиза» только открывает GitHub;
- Android `versionCode` повышен до `110`.

## Web SSH

- E2E проверяет разрыв браузерного WebSocket, закрытие прежней PTY и повторное подключение с новым session ID;
- после повторного подключения проверяется реальный двусторонний вывод;
- существующий физический отчёт подтверждает input, resize, reconnect и close на OpenWrt.

## Длительный прогон

- Netis NX31: 167,4 часа, online, максимальный интервал между выборками 47,2 минуты;
- OpenWrt x86: 167,8 часа, online; зафиксирован и честно отражён обрыв 687,1 минуты с последующим автоматическим восстановлением;
- runtime команд и агента наследует аппаратную сертификацию `0.49.0` только потому, что fail-closed отпечаток исполняемых файлов совпадает.

Машиночитаемый отчёт: `certification/beta-readiness-v0.50.1.json`. Матрица возможностей: `docs/supported-features.md`.
