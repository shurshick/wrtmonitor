# WrtMonitor v1.0.1 - Agent Update Status

Исправление неверного отображения обновлений агента после перехода на публичный выпуск 1.0.0. Сервер, агент и Android: 1.0.1; Android versionCode 127.

## Исправлено

- Web и Android различают установленную версию, источник при последней проверке и действительно доступное обновление. Более старая или равная версия не считается обновлением.
- Старый результат `skipped / downgrade blocked` объясняется как блокировка отката, а не авария. Защита от отката не отключена.
- Агент новее сервера больше не получает ошибочное предложение обновиться назад.
- Настоящие ошибки загрузки, checksum и проверки подписей остаются видимыми. Исходные значения и время проверки в telemetry не переписываются.
- Android корректно отображает старый формат данных при работе с сервером 1.0.0.

## Обновление

Чистая установка не требуется. Обновите сервер через Docker/TrueNAS, затем агенты штатным подписанным обновлением. Android APK подписан прежним ключом, versionCode увеличен до 127. Старый выпуск 1.0.0 не перезаписывается; 1.0.1 получает отдельный тег и комплект файлов.

Проверки и фактические аппаратные результаты: [agent-update-status-1.0.1](docs/agent-update-status-1.0.1.md). Исторические отчёты 1.0.0 остаются отдельными и не выдаются за проверки нового backend.

`RELEASE_INVENTORY.json` фиксирует commit и immutable digest контейнера. Release и agent manifests имеют Ed25519/RSA подписи. Перевод GitHub latest и GHCR latest выполняется только после проверки собранных файлов и CI.
