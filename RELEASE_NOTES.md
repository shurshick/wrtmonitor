# v0.30.0-openwrt-modules

Тестовый релиз модулей OpenWrt. Docker-образ публикуется как versioned и `canary`; `latest` остаётся на выдержанной версии.

## Изменения

- агент передаёт фактическое состояние USB-накопителей, USB-принтеров и LTE/USB-модемов;
- добавлено управление модулями SMB, NFS, FTP, DLNA, печати и модемов;
- установка модуля автоматически подтягивает фиксированный набор зависимостей через apk/opkg;
- после установки и переключения службы выполняется обязательная проверка результата;
- Web UI и Android скрывают неподдерживаемые аппаратные модули и не показывают пустые формы;
- единый исполнимый контракт расширен до 91 команды.

## Проверка

- backend/API, OpenWrt agent и contract tests;
- Android unit, lint и debug build;
- тесты module telemetry, зависимостей, capability-driven UI и post-condition;
- полный контракт 91 команды и Android parity gate.
