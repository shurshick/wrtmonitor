# WrtMonitor v0.50.0 - Beta Readiness

Тестовый релиз приводит экран сведений о приложении и сценарий Android-обновления в понятный пользовательский вид. Контракт управления роутером не менялся.

## Изменено

- экран «О приложении» получил компактную шапку с иконкой, версией, автором и отдельным описанием проекта;
- длинный текст больше не смешан с версией и кнопками в одной строке;
- действие «Скачать обновление» загружает APK и запускает штатный установщик Android;
- переход на GitHub вынесен в отдельную кнопку «Страница релиза»;
- при отсутствии APK приложение не маскирует переход на GitHub под скачивание;
- файлы повторных загрузок получают имя с версией и уникальным суффиксом;
- аппаратная сертификация команд наследуется от `0.49.0` только при полном совпадении отпечатка runtime агента;
- Android `versionCode` повышен до `109`.

## Проверено

- выбор актуального релиза и APK;
- отдельный fallback на страницу релиза при отсутствии APK;
- состояние актуальной версии;
- Android unit-тесты, lint и сборка;
- неизменность runtime агента относительно физически проверенного `0.49.0`;
- release metadata, backend, OpenWrt agent и публикация контейнера выполняются штатным CI.

Сервер обновляется redeploy образа `latest`. Агент получает `0.50.0` штатным автообновлением.
