# WrtMonitor v0.52.3 - Release Candidate

Исправление фактического обновления отдельных пакетов OpenWrt. Новые функции не добавлялись.

## Исправлено

- APK получает команду `upgrade`, а не повторный `add`, поэтому выбранный пакет действительно обновляется;
- операции установки, удаления и обновления явно разделены для APK и opkg;
- агент фиксирует установленную версию до и после операции и целевую версию из каталога;
- Web UI и Android получают свежий список сразу после подтверждённого обновления;
- при отказе журнал показывает пакет, текущую и ожидаемую версии.

После автообновления агента повторите обновление пакета. При успехе запись исчезнет из списка без ожидания следующего интервала telemetry.

Android `versionCode`: `115`. Все версии до `1.0.0` остаются тестовыми.
