# WrtMonitor v0.35.15 — повторная сертификация

Тестовый релиз закрывает полный аппаратный прогон актуального контракта управления.

## Исправлено

- certification runner охватывает все 93 команды, включая SSH-сессию и ограниченный shell-script;
- успешный shell-script возвращает допустимый статус `done`;
- SSH и shell-script используют проверку фактического результата обработчика;
- повторный прогон корректно добавляет команды, появившиеся после создания старого отчёта.

## Аппаратная проверка

- Netis NX31, OpenWrt 25.12.4: 89 PASS, 4 `not_applicable`, 0 ошибок;
- OpenWrt x86, VirtualBox 22.03.5: 88 PASS, 5 `not_applicable`, 0 ошибок;
- для каждой применимой команды проверены повторная доставка, timeout, post-condition и восстановление исходной конфигурации.

На x86 настройки Wi-Fi проверены по UCI. Наблюдаемое состояние радио не проверялось, потому что у стенда нет физического Wi-Fi-модуля.
