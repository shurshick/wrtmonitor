# WrtMonitor v0.45.2 - Agent Recovery

Тестовый стабилизационный релиз закрывает реальный аварийный сценарий: повреждённая или read-only файловая система больше не должна оставлять OpenWrt-агент смесью файлов разных версий.

## Исправлено

- runtime агента устанавливается цельным версионированным поколением;
- рабочий entrypoint заменяется только после подготовки всех библиотек и init-скрипта;
- старый entrypoint не загружает активное поколение с несовпадающей версией;
- перед установкой проверяются запись в системные каталоги и свободное место;
- rollback возвращает единый комплект файлов, а не отдельные части разных версий;
- повторная установка с `--token` получает связанный `device_id` с сервера до изменения UCI;
- installer больше не удаляет `device_id`, если используется существующий token.

## Проверено

- неполное поколение не заменяет рабочий entrypoint;
- полное поколение активируется как единый runtime;
- проверка версии выполняется до preflight, поэтому установленная актуальная версия не даёт ложную ошибку;
- shell-сценарии агента исполняются локально через Git Bash и в Linux CI;
- backend, OpenWrt harness, Android unit/lint/build и Android emulator UI tests.

Схема PostgreSQL и TrueNAS YAML не изменились. Сервер обновляется обычным redeploy образа `latest` после публикации релиза.
