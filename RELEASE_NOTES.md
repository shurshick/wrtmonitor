# WrtMonitor v0.54.0 - Android Expressive Redesign

Android-приложение системно переработано в стиле Material 3 Expressive без изменения API и команд управления роутером.

## Главное

- единая светлая и тёмная дизайн-система WrtMonitor;
- новый компактный обзор состояния сети и семантические статусы;
- edge-to-edge с корректными status bar, navigation bar, safe drawing и IME;
- нижняя навигация на телефоне и Navigation Rail на планшете;
- единые loading, empty, error, offline и unsupported-состояния;
- доступные области касания не меньше 48 dp;
- исправленная навигация настроек и экрана «О приложении»;
- актуальные скриншоты Android в README.

Проверка выполнена на Android 15 emulator с живым сервером и Netis NX31. Функциональные API-контракты не менялись. Android `versionCode`: `119`.

Все версии до `1.0.0` остаются тестовыми.
