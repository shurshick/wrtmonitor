# v0.24.2-ui-polish — Доработка интерфейса

Тестовый патч-релиз исправляет конкретные проблемы компоновки и управления в Web UI и Android.

## Изменения

- выбор светлой или тёмной темы Web UI сохраняется при переходах между разделами;
- блоки наблюдения, автоматизации и восстановления собраны в одну строку, список служб перенесён ниже;
- перезагрузка роутера в списках Web UI и Android оформлена компактной иконкой с подтверждением;
- системная нагрузка показана относительно числа ядер и дополнена исходным `load average`;
- browser smoke проверяет сохранение темы и desktop-компоновку обслуживания.

## Проверка

Backend, Android, shell syntax, OpenWrt harness и контракты команд проверяются автоматически. Опасные действия на физическом роутере требуют отдельного подтверждённого прогона.
