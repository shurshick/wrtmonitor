# WrtMonitor v0.52.0 - Release Candidate

Кандидат на стабильную публичную бету без расширения функциональности. Релиз исправляет узкие места, найденные после `0.51.0`.

## Производительность

- диагностический ZIP получает последние telemetry, метрики и диагностику роутеров пакетными запросами;
- число запросов к PostgreSQL больше не растёт на три запроса для каждого подключённого роутера;
- расчёт свежести агентов также работает одним пакетным запросом.

## Надёжность

- повторное нажатие отправки отзыва в течение двух минут не создаёт дубль;
- один владелец может отправить не более пяти разных сообщений за десять минут;
- Web UI показывает понятное ограничение, API возвращает структурированную ошибку `feedback_rate_limited`;
- PostgreSQL E2E проверяет дедупликацию, ограничение частоты и безопасный архив.

Android `versionCode`: `112`. Все версии до `1.0.0` остаются тестовыми.
