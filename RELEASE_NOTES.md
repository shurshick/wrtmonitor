# WrtMonitor v0.52.2 - Release Candidate

Исправление синхронизации пакетных операций OpenWrt. Новые функции не добавлялись.

## Исправлено

- после пакетной операции агент сразу перечитывает состояние APK/opkg и отправляет свежую telemetry;
- Web UI и Android получают новый счётчик без ожидания следующего планового интервала;
- обновление считается успешным только если пакет больше не находится среди доступных обновлений;
- результат команды содержит актуальное число оставшихся обновлений.

После автообновления агента достаточно обновить выбранный пакет: список и счётчик синхронизируются автоматически.

Android `versionCode`: `114`. Все версии до `1.0.0` остаются тестовыми.
