# v0.16.0-stability — стабилизация платформы

## Что изменилось

- Введены версии контрактов команд и telemetry; CI проверяет одинаковый набор из 76 команд на сервере и в агенте.
- Команды получили idempotency key, защиту от повторного выполнения и проверку результата после изменения конфигурации.
- Очередь команд безопасно работает при нескольких экземплярах сервера через PostgreSQL row locking.
- Android восстанавливает истёкшую сессию одним синхронизированным refresh-запросом и повторно загружает текущий экран.
- Ограничение попыток входа перенесено в PostgreSQL и одинаково работает для API и Web UI.
- Добавлена безопасная ротация ключа OpenWrt-агента с десятиминутным переходным периодом.
- Обновления агента теперь требуют Ed25519-подпись манифеста и SHA-256 каждого файла.
- Миграции защищены PostgreSQL advisory lock; `/live`, `/ready`, request ID и опциональный `/metrics` упрощают эксплуатацию.
- Runtime-образ запускается непривилегированным пользователем и содержит только серверные зависимости.
- CI дополнен pip-audit, CodeQL, dependency review, SBOM, provenance и сборкой Android instrumentation APK.

## Обновление

1. В TrueNAS откройте Custom App, нажмите **Edit → Save**. Образ `ghcr.io/shurshick/wrtmonitor:latest` скачивается заново благодаря `pull_policy: always`.
2. Дождитесь состояния `/ready` = `200 OK`; миграция `0009_stability` применяется автоматически.
3. В разделе **Обслуживание** нажмите **Проверить и обновить** для агента. Чистая переустановка не требуется.
4. Установите Android APK поверх предыдущей версии. `versionCode` повышен до `60`.

Перед обновлением сервера рекомендуется создать резервную копию PostgreSQL.
