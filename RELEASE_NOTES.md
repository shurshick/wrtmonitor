# WrtMonitor v0.53.1 - Wi-Fi Security Fix

Исправлено создание и редактирование гостевых и дополнительных Wi-Fi-сетей.

## Исправлено

- открытую гостевую сеть можно создать без пароля;
- WPA2, WPA3 и смешанный WPA2/WPA3 передаются роутеру без принудительной замены на WPA2;
- пустой пароль сохраняет текущий секрет только у уже защищённой сети;
- при переходе с открытой сети на защищённую Web UI и Android требуют новый пароль;
- быстрое включение гостевой сети не меняет её текущую защиту;
- агент проверяет фактический запуск SSID после изменения и откатывает конфигурацию, если сеть не появилась в эфире.

Android `versionCode`: `118`. Все версии до `1.0.0` остаются тестовыми.
