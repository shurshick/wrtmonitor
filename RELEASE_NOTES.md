# WrtMonitor v0.53.0 - Wi-Fi Access Profiles

Профили доступа теперь работают не только для отдельных клиентов, но и для основной или гостевой Wi-Fi-сети целиком.

## Добавлено

- назначение общего профиля любому фактическому SSID из Web UI и Android;
- суммарные лимиты приёма и передачи для клиентов выбранной сети;
- блокировка сети и недельное расписание доступа;
- создание и редактирование профилей с автоматическим применением изменений;
- observed-состояние: имя профиля, активность расписания и фактические фильтры скорости.

## Надёжность

- новая команда `wifi.set_access_profile` имеет capability, rollback и строгую read-after-write проверку;
- агент не перестраивает неизменившиеся `tc`-фильтры и не пишет UCI на каждом цикле telemetry;
- удаление профиля сначала снимает его со всех наблюдаемых Wi-Fi-сетей;
- x86 без Wi-Fi не получает пустые элементы управления.

Лимит SSID является общим для всей сети. Индивидуальная политика клиента применяется дополнительно.

Android `versionCode`: `117`. Все версии до `1.0.0` остаются тестовыми.
