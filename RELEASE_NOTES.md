# v0.34.0

- Добавлен роутер `/api/v1/account` для доступа к функциям аудита и безопасности.
- Реализован эндпоинт `GET /account/audit` для просмотра истории действий в системе.
- Реализован эндпоинт `GET /account/sessions` для управления активными сессиями пользователя.
- Добавлена возможность принудительного отзыва сессий (Logout from other devices) через `POST /account/sessions/{id}/revoke`.
- Гарантирована полная независимость системы от сторонних облачных сервисов и push-уведомлений.
