# v0.17.1-agent-update-compatibility — обновление старых агентов

## Что исправлено

- Агент `0.15.x` снова может автоматически обновиться до актуальной версии.
- `SHA256SUMS.sig` исключён из legacy-списка checksummed payload-файлов: detached-подпись нельзя включать в подписываемый ею же checksum-файл.
- Installer и updater `0.17.1` по-прежнему отдельно скачивают подпись и обязательно проверяют её встроенным Ed25519 public key.
- Добавлен регрессионный тест, который запрещает возвращать несовместимую структуру release payload.
- Убрано ложное устойчивое состояние «установлен старый агент» после чистого развёртывания: переход со старого комплекта теперь завершается, а не падает с `checksum or syntax verification failed`.

## Обновление

1. В TrueNAS откройте Custom App и выполните **Edit → Save**. Образ `ghcr.io/shurshick/wrtmonitor:latest` будет загружен заново.
2. Дождитесь ответа `200 OK` от `/ready`.
3. Агент `0.15.x–0.17.0` обновится автоматически после ближайшей telemetry. Также можно нажать **Обслуживание → Проверить и обновить**.
4. Установите APK поверх текущего приложения. Версия Android: `0.17.1`, `versionCode 63`.

Повторно удалять роутер из базы или переустанавливать агент не требуется.
