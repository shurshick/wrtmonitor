# v0.30.1-agent-stability

Тестовый стабилизационный релиз сервера и OpenWrt-агента.

## Изменения

- изменение LAN стало идемпотентным: совпадающая конфигурация не перезапускает сеть;
- агент перезапускает только изменённый LAN-интерфейс и проверяет фактический IPv4 после применения;
- исправлен ложный rollback из-за перезаписи переменных UCI-verifier;
- зависшие init-сервисы завершаются по deadline и не блокируют обмен с сервером;
- незавершённые транзакции восстанавливаются или откатываются после старта агента;
- исчерпанные попытки доставки команды теперь фиксируются как конкретная ошибка;
- секреты рекурсивно удаляются из telemetry до сохранения в базе.

## Проверка

- backend/API и OpenWrt agent tests;
- Android unit tests;
- shell syntax, checksum и release metadata;
- реальная очередь команд и идемпотентное изменение LAN на Netis NX31.
