# WrtMonitor v0.55.2 - Web Terminal Contrast

Патч исправляет контраст Web SSH в светлой теме. Backend API, авторизация, telemetry и команды агента не менялись.

## Исправлено

- обычный текст xterm больше не наследует тёмный цвет светлой темы страницы;
- терминал получил полную контрастную палитру для обычных и ANSI-цветов;
- палитра повторно применяется при переключении светлой и тёмной темы;
- скроллбар и системные элементы терминальной области сохраняют тёмное оформление;
- браузерный тест выполняет реальный Web SSH roundtrip в светлой теме и проверяет вычисленные цвета текста и фона.

Web SSH roundtrip и светлая тема проверены в Chromium при desktop-размере `1440x900`. Проверяемая пара цветов: текст `#eef4f9`, фон `#07101c`.

Фиктивные данные и неподдерживаемые операции не добавлены. Runtime OpenWrt не менялся; аппаратное soak evidence Netis NX31 и OpenWrt x86 наследуется по совпадающему fingerprint. Android `versionCode`: `122`.

Все версии до `1.0.0` остаются тестовыми.
