# WrtMonitor v0.36.0 — события и автоматизация

Тестовый релиз добавляет единый центр событий и безопасные сценарии управления OpenWrt.

## Добавлено

- постоянный журнал событий роутеров и сервера с фильтрами, подтверждением, snooze, объединением повторов и автоматической очисткой;
- события online/offline, WAN, клиентов, telemetry и полного жизненного цикла команд;
- правила уведомлений с тихими часами, восстановлением и каналами in-app, webhook, ntfy и SMTP;
- SMTP-пароли хранятся только в переменных окружения сервера и не попадают в БД или API;
- автоматизация по событиям с шаблонами, dry-run, cooldown, часовым лимитом и идемпотентной постановкой команд;
- запрет опасных команд, циклов `command -> command` и неограниченных повторных запусков;
- Web UI и Android получили центр событий, правила уведомлений, сценарии и историю запусков;
- результат сценария меняется только после фактического ответа OpenWrt-агента.

## Проверки

- PostgreSQL migration и интеграционные тесты событий, dedupe, acknowledge, snooze, правил и сценариев;
- проверка отклонения опасных и циклических сценариев;
- backend lint, архитектурные и contract checks;
- Android unit, lint, debug/release assembly и UI test assembly;
- shell syntax, shellcheck, agent harness и browser smoke.

Android `versionCode`: `92`.
