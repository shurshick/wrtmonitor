# WrtMonitor v0.55.4 - Android Overview Polish

Небольшой patch-релиз исправляет компоновку обзора роутера в Android.

## Исправлено

- четыре плитки ресурсов имеют одинаковую высоту, даже когда нагрузка занимает две строки;
- быстрые действия расположены в симметричной сетке 2×3;
- добавлен быстрый переход в раздел «Система»;
- подписи кнопок сокращены и не обрезаются на компактных экранах;
- сохранены минимальная область касания и подтверждение перезагрузки.

## Проверки и ограничения

Backend API, PostgreSQL, Web UI, telemetry и команды OpenWrt не менялись. Android `versionCode`: `124`.

Новый длительный прогон Netis NX31 и OpenWrt x86 для визуального Android patch не выполнялся; владелец разрешил выпуск. Исключение привязано к версии и точному fingerprint неизменного server/OpenWrt runtime. Полный CI, Security, Android emulator, signed APK и deployment acceptance остаются обязательными.

Все версии до `1.0.0` остаются тестовыми.
