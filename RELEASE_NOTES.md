# WrtMonitor v0.52.1 - Release Candidate

Исправление отображения обновлений пакетов OpenWrt. Новые функции не добавлялись.

## Исправлено

- агент корректно читает список обновлений из APK 3 через структурированный `apk query`;
- сервер получает реальное число обновлений, названия пакетов, текущие и доступные версии;
- сохранена совместимость со старым manifest-форматом APK и opkg;
- ошибка проверена на Netis NX31 с OpenWrt 25.12.4: агент обнаруживает те же 54 обновления, что и LuCI.

После автообновления агента новые данные появятся при следующей telemetry или после кнопки «Обновить каталог».

Android `versionCode`: `113`. Все версии до `1.0.0` остаются тестовыми.
