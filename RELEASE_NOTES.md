# WrtMonitor v0.52.4 - Release Candidate

Исправления обслуживания OpenWrt и создания гостевой сети. Новые подсистемы не добавлялись.

## Исправлено

- обновление пакета в Web UI подтверждается отдельно и не перезагружает страницу;
- раскрытый список доступных обновлений остаётся открытым, а после выполнения команды обновляется только карточка пакетов;
- официальный каталог ищет новую версию в текущей ветке OpenWrt, а не повторно предлагает установленную;
- `netis,nx31` сопоставляется с официальным профилем `netis_nx31`; для OpenWrt 25.12.4 найден sysupgrade 25.12.5 с проверяемой SHA-256;
- Android не позволяет впервые включить гостевую сеть без SSID и пароля длиной не менее 8 символов;

Физическая проверка создания гостевой сети выполнена на Netis NX31 с последующим автоматическим восстановлением исходных настроек.

Android `versionCode`: `116`. Все версии до `1.0.0` остаются тестовыми.
